# 《符文余烬》符文系统设计 v1（切片期）

> 玩法设计执行层文档，与 [符文余烬_游戏开发Plan.md]（战略层）配套
> 范围：切片期 20 个符文详细设计 + 数值平衡框架 + 成长曲线
> 数值载体：Luban 配置表（Excel），本文档是表内容的设计稿
> 版本：v1.0 | 日期：2026-10-27

## 一、设计约束（从 Plan 继承，不可违反）

1. **质变配比**：质变型符文 ≥ 60%，数值填充型 ≤ 40%
2. **能耗闸门**：每条链有能耗上限，修饰器带能耗消耗
3. **敌我咬合**：至少 3 种敌人分别克制/利好不同构筑
4. **决策分层**：战斗中只选符文，喘息窗口才组装链
5. **反退化**：同一条链上同一修饰最多 1 个（切片期规则）

## 二、符文表 v1（20 个）

### 2.1 触发器（6 个）——决定"什么时候发动"

| ID | 名称 | 效果 | 能耗 | 类型 | 设计意图 |
|---|---|---|---|---|---|
| T1 | 定时脉冲 | 每 0.8s 自动发动一次 | 0 | 填充 | 基准线，新手默认，稳定但无上限 |
| T2 | 击杀回响 | 每次击杀时发动 | 2 | 质变 | 前期弱后期强，与清屏构筑正循环 |
| T3 | 命中传导 | 每次命中 25% 概率发动 | 2 | 质变 | 利好高频低伤构筑，与"护盾怪"考题互斥 |
| T4 | 冲刺余波 | 冲刺结束后发动 | 1 | 质变 | 把位移技能变成攻击窗口，行为改变最大 |
| T5 | 受伤反击 | 受到伤害时发动，内置 1s 冷却 | 1 | 质变 | 卖血流核心，风险换输出 |
| T6 | 常驻光环 | 效果以自身为中心持续生效（每秒判定） | 2 | 质变 | 走位流核心，解放瞄准 |

**触发器的数值平衡逻辑**：触发频率直接乘在总 DPS 上，因此触发器之间比的是"期望触发频率"——
定时脉冲 = 1.25 次/s（基准）；击杀回响在怪潮期可达 3~5 次/s 但单体 Boss 战 ≈ 0；命中传导 = 命中数 × 0.25。
三者形成**稳定 / 滚雪球 / 高频**的三角选择，没有唯一最优。

## 三、数值平衡框架

### 3.1 能耗经济（链的预算）

| 项目 | 数值 |
|---|---|
| 初始槽位 / 能耗上限 | 3 槽 / 上限 10 |
| meta 第一次解锁 | 4 槽 / 上限 12 |
| meta 第二次解锁 | 5 槽 / 上限 16 |
| 局内稀有强化 | "过载符文"：本局上限 +1（最多 +2） |

**能耗价值锚点**（平衡新符文的标尺）：每 1 点能耗 ≈ 提升 15%~20% 单体有效输出。AOE/控制类按期望命中目标数折算。新符文数值超出锚点 ±30% 就需要回调能耗或数值。

### 3.2 三条保底构筑的能耗校验（切片期必须成立的构筑）

| 构筑 | 链 | 能耗 | 校验 |
|---|---|---|---|
| 站桩弹幕流 | 定时脉冲(0) + 散射(4) + 追踪(3) | 7 | ≤10 ✓ |
| 冲刺地雷流 | 冲刺余波(1) + 地雷(4) + 爆炸(3) | 8 | ≤10 ✓ |
| 环绕走位流 | 常驻光环(2) + 环绕球(4) + 冰冻(3) | 9 | ≤10 ✓ |
| 胡牌示例（需 meta） | 击杀回响(2) + 直射弹(3) + 分裂(3) + 爆炸(3) | 11 | ≤12 ✓（一次 meta 解锁后） |

### 3.3 有效 DPS 模型

```
有效DPS = 效果伤害 × 期望触发频率 × 修饰乘区
```

修饰乘区参考值（单体/多目标期望）：

| 修饰 | 单体乘区 | 多目标乘区（≥5 目标） |
|---|---|---|
| 分裂 | ×1.0 | ×1.8 |
| 弹射 | ×1.0 | ×2.4 |
| 穿透 | ×1.0 | ×2.0 |
| 追踪 | ×1.15（命中率提升） | ×1.15 |
| 燃烧 | ×1.33（DoT 打满） | ×1.33 |
| 爆炸 | ×1.25 | ×2.5 |

设计意图：**单体构筑和多目标构筑在不同场景轮流坐庄**，配合敌我咬合，没有全局最优解。

### 3.4 符文强化（局内成长）

三选一中的"强化链上槽位"选项：每个符文可升 2 级（Lv1→Lv3）。

| 符文类别 | Lv2 | Lv3 |
|---|---|---|
| 触发器 | 频率/概率 +20% | 频率/概率 +20%（累计 +40%） |
| 效果 | 伤害 +30% | 伤害 +30%（累计 +60%） |
| 修饰 | 数值 +25%（弹射次数/分裂数/减速幅度等） | 数值 +25% |

强化数值同样受能耗锚点约束：强化不加能耗，是局内纯成长，但三选一选了强化就放弃了新符文——**机会成本即平衡**。

## 四、成长曲线（15 分钟一局）

### 4.1 节奏-数值总表

| 阶段 | 时间 | 玩家期望 DPS | 杂兵 HP | 同屏上限 | 升级次数(累计) | 体验目标 |
|---|---|---|---|---|---|---|
| 脆弱期 | 0~3 min | 15→40 | 20→45 | 15 | 1→4 | 学会拼第一块符文 |
| 成型期 | 3~7 min | 40→120 | 45→140 | 60 | 4→9 | 构筑闭合，连锁初现 |
| 深化期 | 7~10 min | 120→300 | 140→380 | 120 | 9→14 | 开始针对精英调链 |
| 压力峰值 | 10~13 min | 300→600 | 380→700 | 200 | 14→18 | 精英潮检验构筑 |
| Boss | 13~15 min | 600+ | Boss HP 12000 | 300（召唤潮） | 18→22 | 碾压或惜败，都想再来一局 |

### 4.2 经验曲线

- 升级 n 所需经验：`XP(n) = 8 × n^1.4`（Lv1→2 需 8，Lv10→11 需约 190，Lv20→21 需约 530）
- 经验掉落：杂兵 1~3 XP（按阶段缩放），精英 50 XP，Boss 200 XP
- 掉落磁铁拾取半径 3m（避免捡经验打断走位节奏）

### 4.3 敌人投放曲线

- 投放速率：`每分钟击杀预算 ≈ 玩家DPS ÷ 杂兵HP × 0.7`（0.7 为压力系数，<1 保证玩家始终感觉"差一点清完"，这是幸存者类紧张感的来源）
- 精英投放：第 5 / 9 / 12 分钟各一只，词缀随机
- Boss：第 13 分钟登场，Timeline 演出 5s，两阶段（70% 血量转阶段，转阶段时召唤一波杂兵给"击杀流"构筑提供燃料——Boss 战也要照顾构筑差异）

### 4.4 玩家基础属性

| 属性 | 初始 | 备注 |
|---|---|---|
| HP | 100 | 杂兵触碰伤害 8~15，精英 25，Boss 技能 30 |
| 移速 | 6 m/s | 突进精英 8 m/s（必须冰冻或冲刺应对） |
| 冲刺 | 0.25s 无敌帧，冷却 2.5s | 冲刺余波/冲刺斩的载体 |

## 五、平衡守则（每次改表前读一遍）

1. **新符文先过锚点**：能耗价值锚点 ±30% 以内才允许进表
2. **改数值不改机制**：版本内平衡问题优先调数值，机制改动留给大版本
3. **胡牌合法，唯一最优非法**：允许某些组合明显强（爽感来源），不允许任何组合成为"不选就亏"（埋点看选取率，单符文选取率 >60% 或 <10% 都要回调）
4. **连锁上限于能耗，不限于规则**：玩家发现设计师没想到的连锁是设计成功，不是 bug——只要能耗闸门还在
5. **每个版本保留一份"上帝构筑"样本**：内部测试用的最强构筑，作为难度校准基准

## 六、Luban 表结构建议

`rune.xlsx` 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | T1/E1/M1 编号 |
| name | string | 显示名 |
| category | enum | Trigger / Effect / Modifier |
| energy_cost | int | 能耗 |
| base_value | float | 基础数值（伤害/频率/幅度） |
| params | map | 类型特有参数（弹速/角度/层数等） |
| tags | list | 质变标签、咬合标签（anti_shield / anti_swarm 等，供三选一智能推荐权重用） |
| max_level | int | 可强化次数（切片期=2） |
| desc | string | 展示文案 |

三选一推荐权重：根据链上已有符文的 tags 加权（有 E3 环绕球时 M7 追踪权重 ×2），制造"游戏在懂我"的爽感。

## 七、Playtest 待验证问题清单（Phase 1~2 带着问题测试）

1. 完全不知情的玩家能否在 5 分钟内完成首次拼链？（决策分层是否成立）
2. 三条保底构筑的被选率是否均匀？（有没有明显唯一最优）
3. "胡牌瞬间"（如链式殉爆）玩家是否感知到是自己拼出来的，而不是运气？（构筑归因感）
4. 压力系数 0.7 的紧张感是否合适？太难/太简单的第一反馈时间点在哪？
5. 触发器三角（稳定/滚雪球/高频）的选取分布是否均衡？

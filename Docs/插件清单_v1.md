# 《符文余烬》插件清单 v1

> 目标：只装"现在就会用到、且以后拆不掉"的东西；其余按阶段装，避免空转。
> 当前工程：Unity 6000.3.27f1 / URP 17.3.0 / Input System 1.20.1 / Newtonsoft 3.0.2
> 日期：2026-10-28

---

## 零、结论速查

| 分级 | 插件 | 什么时候 |
|---|---|---|
| **必须（现在就加）** | Burst、Collections、Mathematics | W3 之前（Job/空间哈希/Flow Field 的编译前提） |
| **必须（W3 加）** | UniTask、PrimeTween | W3 玩法闭环（异步编排 + 打击感） |
| **推荐（W3 加）** | VContainer | W3 之前，越晚接入越贵 |
| **可选（用到再说）** | Behavior Designer、Odin、Memory Profiler | W4 Boss / 编辑器效率 / W5 性能冲刺 |
| **按阶段后置** | YooAsset、FMOD、Steamworks.NET、HybridCLR、Luban、NGO | Phase 2 / 3 / 轨 B |
| **一定不装** | DOTween、LeanTween、Rewired、A*、Addressables、DOTS、Corgi/TopDown Engine、Game Creator、NodeCanvas/PlayMaker、Feel、Photon/Mirror、Plastic | 永不（理由见第四节） |

**一句话**：现在只加 5 个（Burst / Collections / Mathematics / UniTask / PrimeTween），VContainer 看你要不要学 DI。其余全部后置。

## 一、必须现在加：Job 三件套

| 包 | 版本（Unity 6.3 已验证） | 用途 | 为什么现在 |
|---|---|---|---|
| `com.unity.burst` | **1.8.31** | 把 Job 编译成 SIMD 原生代码 | Flow Field / 空间哈希 / 弹幕碰撞全要它；现在只是 URP 的传递依赖，**显式声明才不会被上游移除** |
| `com.unity.collections` | **2.7.1** | `NativeArray` / `NativeParallelMultiHashMap` | 空间哈希的桶、Flow Field 的三张场都用它 |
| `com.unity.mathematics` | **1.3.3** | `float3` / `math.*` | Burst 友好数学库；Job 里不能用 `UnityEngine.Random`，要用 `Unity.Mathematics.Random` |

**导入方式**：Package Manager → Add package by name → 填上面三个包名（不写版本则取最新 verified）。

**注意**：
- 这三个当前在 `packages-lock.json` 里是传递依赖（depth > 0），必须提升为 manifest 直接依赖，否则哪天 URP 不再带它们，编译直接断。
- 加完之后跑一次 EditMode 测试（43 个），确认没有因为 Burst 的编译设置变化而失败。
- Job 里禁用托管类型（`class`、`string`、`List<T>`），这是后面写 Flow Field 时最容易踩的。

## 二、必须 W3 加：UniTask + PrimeTween

### 2.1 UniTask（Cysharp）

| 项 | 内容 |
|---|---|
| 版本 | **2.5.10+**（Unity 6 兼容） |
| 用途 | 波次编排、场景/资源加载、UI 过渡、取消令牌（`CancellationToken`） |
| 为什么必要 | 协程不能返回结果、不能 try/catch、每帧分配；UniTask 零 GC、可取消、可组合。面试里"异步流管理"是加分项 |
| 导入 | OpenUPM `com.cysharp.unitask`，或 Git URL `https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask` |
| 风险 | 如果开了 **Enter Play Mode Options → Disable Domain Reload**，所有静态状态要手动重置（`UniTask` 自己也要求）。W3 先不开这个选项 |

**什么时候用**：W3 的波次循环（`while (runActive) { await SpawnWave(); await Delay(...); }`）、加载、结算过渡。**不要**用它替代所有 `Update`——每帧逻辑还是 `Update`。

### 2.2 PrimeTween

| 项 | 内容 |
|---|---|
| 版本 | **1.1.x**（Asset Store 免费版够用） |
| 用途 | 顿帧、震屏、受击缩放、UI 弹出、飘字 |
| 为什么必要 | 打击感是切片期三条验收线之一；PrimeTween 零分配、比 DOTween 快、API 更现代。**替代 DOTween**，不要两套并存 |
| 导入 | Asset Store 搜 PrimeTween → Import |
| 风险 | 免费版功能足够；不要同时装 DOTween（同名扩展方法会冲突） |

**具体用在哪**：命中顿帧（`Tween.TimeScale` 或自写 `Time.timeScale` 脉冲）、受击缩放（`transform.DOPunchScale` 风格）、升级卡牌弹出、Boss 出场。

## 三、推荐 W3 加：VContainer（可跳过）

| 项 | 内容 |
|---|---|
| 版本 | **1.16.x** |
| 用途 | 依赖注入：把 `ITableProvider` / `IRuneWorld` / `ISaveStore` / `IRandom` 注册到容器 |
| 为什么推荐 | 现在已经 7 个接口，手工 `new` 会散落；越晚接入越像重构。面试讲"分层架构 + DI"也需要它 |
| 导入 | OpenUPM `jp.hadashikick.vcontainer` |
| 什么时候可以不装 | 如果你只想快速做玩法、不想学 DI，就用现有的"组合根 + 构造函数注入"（`RuneCaster` 已经是这个模式），完全够 solo 用 |
| 风险 | IL2CPP 裁剪需要 `link.xml`；热更程序集里的注册要放在主包初始化之后 |

**我的建议**：装。现在只有 5 个 MonoBehaviour 需要注入，接入成本最低；等到 20 个类再接，就是一周的重构。

## 四、明确不装（以及为什么）

| 插件 | 为什么不用 |
|---|---|
| **DOTween / LeanTween / iTween** | 与 PrimeTween 功能完全重叠；两套补间同时存在会出现同名扩展、时间轴互相干扰。选一个就用 PrimeTween |
| **Rewired** | Input System 已经覆盖键鼠/手柄/重绑/多设备，Rewired 是重复付费 |
| **A* Pathfinding Project** | 我们明确走 Flow Field（同目标数百单位），A* 是反向选型 |
| **Addressables** | 与 YooAsset 二选一；YooAsset 更贴国内团队习惯、热更链路更完整。两个都装是灾难 |
| **DOTS / Entities** | 文档已明确不学全套；成功幸存者独游几乎都是 GameObject + 池 + 自写碰撞 |
| **Corgi Engine / TopDown Engine / Game Creator** | 成品框架会锁死架构，且和"作品集展示系统设计"直接冲突——面试官会问"这是你写的还是框架给的" |
| **NodeCanvas / PlayMaker** | 与 Behavior Designer 二选一；可视化脚本会让"代码可讲性"下降 |
| **Feel / MMFeedbacks** | 打击感与 PrimeTween 重叠；再叠一层反馈框架，调参会变成黑箱 |
| **Inventory System / Dialogue System** | 本作没有背包与对话需求 |
| **Photon / Mirror** | 联机后置且已选 NGO（Unity 官方），三选一即可 |
| **Plastic SCM / Unity Version Control** | Git + LFS 已够，solo 不需要第二套版本控制 |
| **Cinemachine** | 我们的俯视相机只有 50 行、固定俯角、指数跟随；Cinemachine 的混合/轨道能力用不上，反而多一层配置 |
| **Odin Inspector**（默认不装） | 付费、会改变资产序列化格式；solo 用 Editor 脚本 + 自定义 Inspector 就够。预算宽裕再考虑 |
| **2D Animation / Tilemap / Sprite 工具** | 3D 俯视不用；Tilemap 模块留着不影响 |

## 五、按阶段后置

| 插件 | 阶段 | 触发条件 |
|---|---|---|
| **YooAsset 2.2.x** | Phase 2 | 资源 > 200MB，或需要边玩边下 / 分包。接入点已经留好：`IAssetLoader` |
| **Memory Profiler** | W5 性能冲刺 | 免费官方包，查内存快照；不是常驻依赖 |
| **Behavior Designer**（付费 ~$90） | W4 Boss 前再决定 | 只给精英/Boss 用；杂兵自写 FSM。不买也能做完 |
| **FMOD** | Phase 3 | 需要参数化音频/动态混音时；切片期 `AudioSource` 够 |
| **Steamworks.NET** | 上架前 | 成就/云存档/Demo 发布；没有 Steam 账号前装了也测不了 |
| **HybridCLR** | 轨 B（Phase 2 末尾做 1 天最小验证） | Steam 可直接更新，代码热更收益低；先留 asmdef 分层即可 |
| **Luban** | 轨 B（表 > 8 张时） | 现在 1 张表，CSV + 生成器足够；迁移点已留：`ITableProvider` |
| **NGO**（`com.unity.netcode.gameobjects`） | 轨 B | 双人合作模式；接口已留：`IInputSource` / `ID 寻址` |
| **Unity Analytics** | 可选 | 更推荐本地 JSON 埋点（离线、隐私、无网络依赖） |

## 八、版本兼容注意（Unity 6.3）

- **Burst 1.8.31 / Collections 2.7.1 / Mathematics 1.3.3**：当前 lock 里的版本，直接用。
- **UniTask 2.5.10+**：低于 2.5 的版本在 Unity 6 上可能有 `PlayerLoop` 兼容问题。
- **PrimeTween 1.1.x**：确认 Import 后没有和 `UnityEngine.UI` 的扩展方法冲突。
- **VContainer 1.16.x**：IL2CPP 构建前补 `link.xml`，否则反射注册可能被裁剪。
- **YooAsset 2.2.x**：需要 Unity 2022.3+，Unity 6 可用；初始化流程要放在 `AppBootstrap` 之后。
- **HybridCLR**：Unity 6.3 支持需现场验证（6.x 系列较新），这也是它后置的原因之一。

## 十、最终建议（一句话版）

**现在只装 5 个**：`Burst`、`Collections`、`Mathematics`、`UniTask`、`PrimeTween`。
**VContainer 看你是否想学 DI**——想学就现在装，不想学就不装，现有构造函数注入够用。
**其余全部等到有明确触发条件再装**，尤其是 YooAsset / FMOD / Steamworks / HybridCLR。
**永远不要装**：DOTween、Addressables、A*、Rewired、DOTS、成品框架。

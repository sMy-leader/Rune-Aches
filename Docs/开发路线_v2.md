## 一、目标与优先级

### 唯一硬目标

**6 周内做出可录 demo、可投递的求职切片。**

不是"做一款能上架的游戏"。切片 = 一条能讲深的主线 + 可玩的 15 分钟循环 + 三份技术文档。

### 优先级

1. **核心循环闭合**（杀怪 → 升级 → 拼链 → 继续杀）
2. **能被看见**（demo 视频、录屏、截图）
3. **能讲清**（架构文档、性能对比、设计取舍）
4. 内容量（符文数量、敌人数量、群系）

### 明确不做 / 后置

- 联机（NGO）、热更（HybridCLR）、Luban 全量、FMOD、Steamworks
- 村庄/城市群系、自由节点图、每日挑战、分享码
- 正式美术全套（先用玩家 + Troll + 灰盒场景）

## 二、阶段计划

### W3a 收尾：事件总线与 5 种触发器（2~3 天）

**目标**：让 T2/T3/T4/T5/T6 真正能触发，而不是只有 T1 定时。

| 任务 | 实现 |
|---|---|
| 事件总线 | `CombatEventBus`：`OnHit` / `OnKill` / `OnDash` / `OnInjury` / `OnAuraTick` |
| T2 击杀回响 | 击杀事件 → `RuneCaster.Cast()`，带 `meta.NextDepth()` |
| T3 命中传导 | 命中事件 + 0.05s ICD + 25% 概率 |
| T4 冲刺余波 | `PlayerController` 冲刺结束发事件 → E5 线伤 |
| T5 受伤反击 | `PlayerHealth.ApplyDamage` 发事件 + 1s ICD |
| T6 常驻光环 | 每 0.5s tick，以玩家为中心 `DamageArea` |
| 递归闸门 | 所有事件派生施法都走 `RuneRules.CanTrigger(depth)` + `ProcBudget` |
| 攻击命中帧 | Attack clip 加 Animation Event，替换固定 0.5s |
| 数值调整 | Troll 伤害 15→10，冷却 1.2→1.5s；玩家 100 HP |

**验收**：

- Play 里 5 种触发器都能观测到（HUD 或日志）
- 击杀回响 + 爆炸不会卡死/无限递归
- 43+ 测试全绿，构建成功

### W3b：循环闭合（3~4 天）

**目标**：杀怪 → 掉经验 → 升级 → 三选一 → 链变化 → 继续杀。

| 任务 | 说明 |
|---|---|
| 经验掉落 | 敌人死亡掉经验球；磁吸范围 3m |
| 等级曲线 | **预算驱动**：15 分钟升 20 级，用预估总 XP 反推每级需求 |
| 三选一 UI | uGUI + 代码生成；卡牌 320×440；图标 60% 面积 |
| 符文池 | 按类别/已拥有/已满级筛选；避免重复 |
| 波次生成 | 3 分钟验证版 → 15 分钟；每波 3~5 只 Troll 替代品 |
| HUD | HP / 经验 / 计时 / 波次 / 链缩略 / 开火模式 |
| 链编辑器静态原型 | 4 槽 + 符文库 + 预览；先假数据（可与三选一并行） |

**验收**：

- 连续玩 3 分钟：杀怪→升级→选符文→链变化→继续杀
- 至少两条构筑手感不同（弹射燃烧 vs 分裂爆炸）
- 玩家会死，死亡后能重开

### W3c：打击感与结算（2~3 天）

| 任务 | 说明 |
|---|---|
| 顿帧 | 命中/击杀 0.05s 时间缩放，走 `ITime` |
| 震屏 | `TopDownCamera.AddTrauma`，按伤害占比 |
| 伤害数字 | 对象池 + 聚合显示（0.2s） |
| 命中 VFX | 3 个：物理/元素/爆炸 |
| 结算面板 | 存活时间/击杀/等级/构筑链/再来一局 |
| 性能基线 | Profiler：300 敌人 / 500 弹幕；记录 CPU/GPU/Draw Call |

**验收**：

- 连续玩 3 分钟不报错
- 60fps（灰盒 + 当前资产）
- 结算能显示构筑链

### W4：内容扩展（5~7 天）

| 任务 | 说明 |
|---|---|
| 远程怪 | `Chase → Aim(0.4s) → Fire → Reposition` |
| 自爆怪 | `Chase → Fuse(0.8s，可打断) → Explode` |
| 精英词缀 | 护盾（吸收 40% / 护盾值 200）、分裂、加速 |
| Boss | 两阶段；出场/阶段转换/技能预警 |
| Troll 降级 | 从"唯一敌人"改为"精英原型" |
| 第二批资产 | 远程/自爆/场景模块/树石边界 |

**验收**：

- 三种敌人剪影与行为可区分
- Boss 有至少 2 个阶段
- 300 单位性能基线有数据

### W5：完整度与平衡（5~7 天）

| 任务 | 说明 |
|---|---|
| 20 符文补齐 | E6 光束、E7 召唤、M5 冰冻等 |
| 链编辑器正式版 | 拖拽、预览 DPS、错误原因、手柄导航 |
| 平衡 | 能耗锚点、经验曲线、Troll/精英/Boss 数值 |
| 性能冲刺 | 空间哈希接弹丸、VAT/降频、对象池、Draw Call |
| 可访问性 | 色盲模式、震屏开关、伤害数字开关、字号 |

**验收**：

- 5 种构筑手感明显不同
- 300 单位 / 500 弹幕有 60fps 基线
- 链编辑器能不看代码拼出目标链

### W6：试玩与投递（3~5 天）

| 任务 | 说明 |
|---|---|
| 5~10 人试玩 | 观察不说话；记录首次拼链耗时；问"想再来吗" |

| demo 视频 | 40 秒：拼装→战斗→质变 |

**验收**：

- 试玩者中 ≥5/10 主动说"想再来一局"
- demo 视频能讲清"符文链是什么"
- 简历可投

## 五、风险与 kill criteria

| 风险 | 概率 | 应对 |
|---|---|---|
| 试玩者不觉得"想再来一局" | 高 | **Kill criteria**：<5/10 就停内容，改核心循环；两轮不行缩成"符文链 + Boss"小 demo |
| 学业/实习挤压时间 | 高 | 每周最低 2 符文 + 1 敌人；周末不排硬任务 |
| 资产超标导致跑不动 | 高 | 写实 PBR 只给 Boss/精英；杂兵 800~2k 面/≤16 骨骼或 VAT |
| 平衡崩坏 | 中 | 能耗闸门 + 预算驱动经验 + 每周埋点 |
| UI 做不完 | 中 | 先静态原型，再做交互；Debug HUD 兜底 |
| MPB 破坏 SRP Batcher | 中 | W5 性能冲刺时评估 per-instance 属性/顶点色 |

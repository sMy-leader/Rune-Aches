## 一、模型放哪里

**统一先放这里，不要直接拖进 Characters/Enemies：**

```
Assets/Art/Incoming/
```

放进去后 Unity 会自动套用 `ModelImportPostprocessor` 的设置。等验收通过，再按命名规范移动到对应目录。

如果你把模型放在工程外，也可以直接告诉我本地绝对路径，我用 MCP 的 `import_model_file` 导入。

---

## 二、六步导入流程

### 1. 放入 Incoming

支持 `.fbx` / `.obj` / `.glb` / `.gltf`。贴图可以和模型放在同一目录，Unity 会自动关联。

### 2. 等待导入完成

Unity 会自动：

- Scale = 1、使用文件单位（1 unit = 1m）
- 网格不压缩、Read/Write 关闭
- 不导入相机/灯光
- 动画压缩统一
- 贴图按目录限制 512/1024，法线/遮罩不按 sRGB

### 3. 跑验收

菜单：

```
Rune Ashes/Assets/Audit Models
```

生成 `Docs/资产盘点报告.md`，包含面数、顶点、骨骼、动画 clip、材质、命名与 PASS/WARN/FAIL。

### 4. 看报告，决定去留

| 结论 | 含义 | 动作 |
|---|---|---|
| **PASS** | 符合预算 | 归位、换材质、登记台账 |
| **WARN** | 可用但需注意 | 归位；记录风险，W5 性能冲刺时处理 |
| **FAIL** | 超预算/骨骼过多/命名错误 | 先减面、降骨骼或换资产，不要进场景 |

### 5. 归位与命名

| 类型 | 目录 | 命名 |
|---|---|---|
| 玩家 | `Characters/` | `CH_Player_A.fbx` |
| 近战怪 | `Enemies/` | `EN_Melee_A.fbx` |
| 远程怪 | `Enemies/` | `EN_Ranged_A.fbx` |
| 自爆怪 | `Enemies/` | `EN_Bomber_A.fbx` |
| Boss | `Enemies/` | `EN_Boss_Forest.fbx` |
| 地面 | `Environment/Ground/` | `ENV_Ground_Moss_01.fbx` |
| 树/石/摆件 | `Environment/Props/` | `ENV_Tree_Dead_01.fbx` |
| 图标 | `UI/RuneIcons/` | `UI_RuneIcon_T1.png` |

文件名只用英文、数字、下划线；ID 必须与数据表一致。

### 6. 换材质 + 登记

- 把模型所有 Renderer 的材质换成 `Assets/Art/Materials/MAT_Stylized_Default.mat`（或基于它新建的变体）。
- 在 `Docs/资产台账.md` 登记来源、授权、导入日期、验收结论。
- **不要保留资产自带的材质**，否则风格和合批都会失控。

## 三、验收阈值

| 类型 | 三角面 | 贴图 | 骨骼 | 动画 |
|---|---:|---:|---:|---:|
| 玩家 | 4k~8k | 1024 | ≤32 | 6 clip |
| 杂兵 | 800~2k | 512 | ≤16 或 VAT | 4 clip |
| 精英 | 3k~6k | 1024 | ≤24 | 6 clip |
| Boss | 15k~25k | 2048 | ≤48 | 8~12 clip |
| 场景模块 | 200~1k/件 | 512/1024 | 无 | 无 |

自动验收工具按"玩家 8000 / 杂兵 2000 / 场景 1000 / Boss 25000"判定；超过 1.5 倍记 FAIL，超过 1 倍记 WARN。

---

## 四、第一批建议（只导这三个）

不要一次把所有模型拖进来。第一批只导：

1. **玩家**：验证比例、朝向、骨骼、动画。
2. **一个近战杂兵**：验证敌人材质与剪影。
3. **一块地面 tile**：验证场景模块的 2m 网格与拼接。

跑通这三个，再导远程、自爆、树/石/边界。Boss 和装饰留到 W4。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 模型是粉红色 | 材质没换或 Shader 丢失 | 换成 `MAT_Stylized_Default` |
| 模型特别大/特别小 | FBX 单位不是米 | 检查导出单位；不要在代码里补 Scale |
| 模型背对镜头 | 朝向不是 +Z | 在建模软件里转，或导入设置里调整 |
| 动画不动 | 没生成 Avatar / 动画类型不对 | 检查 Rig 的 Animation Type（Humanoid/Generic） |
| 面数爆表 | 写实资产 | 减面，或只给 Boss/精英 |
| 骨骼 30+ | 写实角色 | 杂兵换低模；否则 300 单位跑不动 |
| 场景拼接穿帮 | 模块不是 2m 网格/pivot 不在底部 | 先做 40×40 测试场，不要直接搭关卡 |
| 贴图内存高 | 4K 贴图 | 降到 1024，开压缩 |

## 六、资产台账模板

见 `Docs/资产台账.md`。每件资产至少登记：

- ID / 文件路径
- 来源（商店/免费库/AI/自制）
- 授权与商用条款
- 导入日期
- 面数 / 骨骼 / 贴图
- 验收结论（PASS/WARN/FAIL）
- 备注（需要减面、替换、AI 披露等）

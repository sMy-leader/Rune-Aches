## 授权检查清单

- [ ] 商店资产：保留购买凭证 / 订单号 / 发票。
- [ ] 免费库：确认 CC0 或 CC-BY；CC-BY 必须署名。
- [ ] AI 生成：记录 provider、模型、prompt、生成日期；Steam 商店页需披露 AI 生成内容。
- [ ] 字体：保留 OFL 许可证文件；不要用"免费下载"但条款不明的字体。
- [ ] 音频：确认 loop/商用/改编权限；Sonniss 等免费包要逐条看授权。
- [ ] 禁止：来源不明的 rip、无授权同人素材、影视/游戏提取资源。
- [ ] 每次导入后更新本表；验收结论与 `Docs/资产盘点报告.md` 保持一致。
